# Checklist de implementación y auditoría

Marcar cada punto como Pasa / Falla / No aplica / No probado, adjuntando evidencia.

- [ ] Estructura semántica: título de página, encabezados jerárquicos, regiones y enlace de salto.
- [ ] Imágenes informativas con alternativa; decorativas ocultas a tecnologías de apoyo.
- [ ] Botones con texto/nombre descriptivo; enlaces para navegación; iconos no ambiguos.
- [ ] Todo por teclado; orden de foco, foco visible y no tapado; Escape cuando corresponda.
- [ ] Formularios con etiquetas, agrupación, instrucciones, errores asociados y anuncio de cambios.
- [ ] Contraste de texto 4.5:1 normal / 3:1 grande; interfaz no textual 3:1 según WCAG.
- [ ] Estados no dependen solo del color; gráficos etiquetados y explicados.
- [ ] Zoom 200%, reflujo a 320 CSS px, texto ampliado y espaciado sin pérdidas esenciales.
- [ ] Objetivos táctiles WCAG 2.2 AA 24×24 CSS px o excepción; preferible 44–48.
- [ ] Alternativa a gestos de arrastre/deslizamiento y acciones complejas.
- [ ] Subtítulos, transcripciones y alertas visuales cuando correspondan.
- [ ] Movimiento reducido y ausencia de destellos peligrosos.
- [ ] Alto contraste / colores forzados; enlaces reconocibles sin color.
- [ ] Lenguaje claro, diseño consistente, tiempo suficiente y confirmación de acciones críticas.
- [ ] WAVE/axe/Lighthouse ejecutados; teclado y NVDA/VoiceOver/TalkBack probados manualmente.
- [ ] Evidencias por ruta, viewport, navegador, lector, fecha, fallos y correcciones.
